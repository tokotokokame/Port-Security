# Port Security v1.2 リリースノート

データの正確さと根拠の示し方を見直した版です。画面構成と見た目、オフライン動作は変わりません。

## 重要: 更新の前に
- v1.2 から、正式な署名鍵で署名した APK だけを公開します。**v1.0.31 以前（デバッグ鍵で署名）から更新するときは、いったんアンインストールしてから入れ直してください。** 保存しているデータはないため、失われるものはありません。
- リリースの説明に署名証明書の SHA-256 を載せています。

## データの訂正
- 根拠を特定できない「CISA分析」「CISA緊急勧告」「CISA Bad Practice」「Mirai」などの表記を、原文の記述に置き換えました。CVE 公表後のスキャン開始時間の統計は、出典（Palo Alto Networks の 2021 年の観測）に合わせて訂正しました。
- High の 27 件を一次資料で再検証し、12 件を維持、15 件を Medium にしました。根拠はリスク評価に表示されます。
- FortiGate のログを FortiOS 7.4 / 7.6 の公式資料で照合し直し、版ごとに表示します（7.6.3 で SSL VPN トンネルモードが廃止されたことも記載）。
- NEC IX の、公式資料で確認できないフィールドを削除し「未確認」にしました。
- 「認証のないサービス」に既定アカウント（T1078.001）を対応付けていた誤りを直しました。

## 表示の追加
- ログに分類 [A] / [B]（ポート固有）・[B']（プラットフォーム共通）・[C/D]（境界機器・経由）を表示。「ポート固有のログなし」は A・B がないときだけ表示します。
- ATT&CK との関連に区分（直接・汎用・推定・未確認）と根拠の種類（ATT&CK 公式の記述・一次資料・アプリ内の関連付け）を表示。
- ツールの技術を「ATT&CK 公式 (uses)」と「攻撃手法経由」に分けて表示。
- リスク評価に、一次資料の要素だけで判定した「サービス固有のリスク」と露出条件を追加。
- 攻撃手法に、ATT&CK 対応付けと本文の確認状態を分けて表示。出典に確認方法（原文・公式 STIX・検索結果のみ など）を表示。
